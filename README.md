# Lads Darts Predictor

Create a mobile-friendly web app for a "Darts Predictor League" for me and my friends. 

Key Features:

1. User Authentication: A simple login or name-selection screen so friends can log in and view their personal dashboard.

2. Admin Dashboard: A private section for me (the admin) to add upcoming darts matches (Player A vs Player B) and later input the final scores.

3. Prediction Page: A screen for users to see upcoming matches and submit their predictions (e.g., predicted winner and exact leg score).

4. Rules & Scoring: 

   - 3 points for guessing the exact winner AND the exact leg score.

   - 1 point for guessing the correct winner but the wrong leg score.

   - 0 points for an incorrect winner guess.

5. Leaderboard: A live ranking table sorting my friends from highest to lowest points based on their successful predictions.

Make the design look modern, clean, and optimized for a smartphone screen with dark mode accents.
